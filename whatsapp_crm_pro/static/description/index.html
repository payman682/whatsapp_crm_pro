WhatsApp CRM Pro - Meta WhatsApp Integration for Odoo

Connect WhatsApp Business with Odoo CRM and automatically convert customer messages into sales opportunities.

Key Features

  • Receive WhatsApp messages inside Odoo
  • Auto-create CRM leads from WhatsApp
  • Reply to WhatsApp directly from CRM
  • Conversation timeline inside opportunities
  • WhatsApp analytics dashboard
  • Multiple WhatsApp accounts

Setup Instructions

  1. Create a Meta WhatsApp Business API app
  2. Add Odoo webhook URL
  3. Add Phone Number ID in WhatsApp CRM - Accounts
  4. Enable Auto Lead Creation
